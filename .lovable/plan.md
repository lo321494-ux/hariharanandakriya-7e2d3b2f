# Sincronizar el sitio con el repositorio original

## Objetivo
Reemplazar la reconstrucción aproximada por el código fuente exacto del repositorio indicado, conservando todo su contenido, navegación, imágenes, presentación y efectos.

## Implementación
- Sincronizar las diez páginas y sus metadatos desde el repositorio original.
- Incorporar la cabecera, pie, portada animada, fondo atmosférico, escena visual y componentes compartidos originales.
- Restaurar íntegramente los estilos, animaciones, estados móviles y efectos tridimensionales.
- Incorporar los recursos y el índice completo de documentos originales.
- Añadir únicamente las dependencias que exige el código original.
- Mantener el archivo de utilidades original; tiene seis líneas y no contiene el error señalado en la línea 8.

## Verificación
- Comprobar que el proyecto no tenga errores de tipos.
- Abrir y recorrer las diez páginas en escritorio y móvil.
